# ระบบบริหารจัดการรถเมล์สำหรับมหาวิทยาลัยพะเยา
## คำอธิบายโครงการ
ระบบนี้เป็นแอปพลิเคชัน สำหรับบริหารจัดการระบบรถเมล์ภายในมหาวิทยาลัยพะเยา โดยใช้ Flutter Golang และ PostgreSQL

1.) การเตรียมฐานข้อมูล ก่อนการสร้าง project

ติดตั้ง PostgreSQL
- ดาวน์โหลดและติดตั้ง PostgreSQL จาก [PostgreSQL Downloads](https://www.postgresql.org/download/)

- ตั้งค่า `username` เป็น `postgres` และ `password` ตามที่กำหนด

สร้างฐานข้อมูล :เปิด Terminal หรือ Command Prompt แล้วพิมพ์: psql -U postgres

จากนั้นสร้างฐานข้อมูลใหม่: CREATE DATABASE UP_Transit_test;

เชื่อมต่อกับฐานข้อมูล: \c UP_Transit_test;

จากนั้นนำคำสั่งจาก SQL ไป RUN บนตัว Database ที่ใช้งาน

2.) การ import project

Clone Project

เปิด Visual Studio Code  กด( Ctrl + Shift + G ) เลือก Clone Repository 

ติดตั้ง Dependencies:

เมื่อ Clone Repository ได้แล้วเปิด Terminal ใน Visual Studio Code พิมพ์คำสั่ง : flutter pub get

สำหรับ Backend พิมพ์คำสั่ง : go mod tidy

*** หากติดปัญหา Dart SDK version  ให้ทำการ พิมพ์ flutter upgrade ใน TERMINAL แล้ว	ทำการ พิมพ์ flutter pub get ***

3.) การตั้งค่าฐานข้อมูลการตั้งค่าฐานข้อมูล

ไปที่ไฟล์ .env แก้ password เป็นของตัวเองที่ตั้งไว้:

    DB_USER     = "postgres"
    DB_PASSWORD = "your_password"
    DB_NAME     = "UP_Transit_test"
    DB_HOST     = "localhost"
    DB_PORT     = "5432"

ตั้งค่า Database ใน VS Code:

ติดตั้ง Database Client extension

เปิด Database Explorer

กรอกข้อมูล:

Host: localhost
Username: postgres
Password: your_password
Database: UP_Transit_test
Port: 5432

กด Connect

4.) คำสั่ง build project

*** ก่อน build อย่าลืมแก้ IP ให้เป็น IP ของตัวเอง ที่ frontend/page/configip/config.dart ***

*** เช็ค IP เปิด cmd พิมพ์คำสั่ง : ipconfig ***

Backend

พิมพ์คำสั่ง: 

    cd \lib\backend

    go run main.go 

ใน TERMINAL

Frontend

พิมพ์คำสั่ง:

    cd \lib\frontend

    flutter run 

ใน TERMINAL

5.)การรัน Emulator หรือโทรศัพท์ Android
การรันบน Emulator

เปิด Android Studio ไปที่ Project มุมซ้ายบน จากนั้นเลือก More Action ต่อมา 

เลือก Virtual Device Manager ที่มุมซ้ายบนจะมี Icons รูป (+) เพื่อสร้างเครื่องจำลอง 

ต่อมาเลือกขนาดอุปกรณ์ ต่อมา เลือก System Image เมื่อได้อุปกรณ์ตามต้องการแล้ว กด finish

จากนั้นเปิด visual studio code ไปที่ไฟล์งานหลัก กดที่ Chrome (web-javascript) 

มุมขวาล่างเพื่อเปลี่ยนอุปกรณ์ที่จะทำการจำลอง เลือกอุปกรณ์จำลองที่เราสร้างขึ้นจาก Android Studio


การรันบนมือถือจริง 

เปิด Developer Mode บนโทรศัพท์ Android 

เปิด USB Debugging 

เชื่อมต่ออุปกรณ์กับคอมพิวเตอร์
